# Diamond Rails

Monorepo for maintained Fabric versions of Diamond Rails.

## Versions
- `1.21.11`: Legacy/reference version.
- `26.1`: Minecraft 26.1 release line.

## Build
Run the Gradle wrapper inside the target version folder.

- `1.21.11`: `.\gradlew.bat build`
- `26.1`: `.\gradlew.bat build`
