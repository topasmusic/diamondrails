# Diamond Rails (Minecraft 26.2)
A Fabric mod that makes minecarts useful as late-game transportation by adding high-speed powered rails. This fork updates arthomnix's Diamond Rails for Minecraft 26.2 on Fabric.

# Diamond Rails
A mod that makes minecarts and rails viable as late-game transport, adding three new types of powered rails that are much faster than vanilla.

## Rails
### Powered rails (Vanilla, unchanged)
Top speed of **8 blocks per second**.

### Diamond rails
Top speed of **32 blocks per second**.
Crafted with the same recipe as powered rails, but with diamonds instead of gold.

### Enhanced diamond rails
Top speed of **90 blocks per second**.
Crafted by enhancing a diamond rail with a lapis block and a chorus fruit in a smithing table.

### Netherite rails
Top speed of **159 blocks per second**.
Crafted by upgrading an enhanced diamond rail with a netherite smithing template and a netherite ingot in a smithing table.

## Building railways
- It is currently impossible to turn corners or go uphill or downhill while traveling on modded rails at full speed.
- Use vanilla powered rails before turns to slow minecarts down safely.
- Vanilla powered rails are also recommended before slopes.
- Straight, flat tracks work best.
- A small number of modded rails can carry a minecart a long distance, especially netherite rails.
